# S&U Professional Luxury Unisex Salon

A premium luxury salon website built with HTML, CSS and vanilla JavaScript.

## Pages
- index.html — home page with hero, services, experience, and weather widget
- about.html — brand story, philosophy, and collaboration details
- services.html — service menu and pricing cards with category tabs
- gallery.html — filterable gallery and lightbox preview
- contact.html — contact details, opening hours, and appointment enquiry form

## Folder structure
- css/
- js/
- assets/

## How it connects
- Each page shares the same header, footer, color palette and typography.
- JavaScript files handle the mobile menu, gallery filtering, weather fallback widget, and page reveal animations.
- Images are intentionally kept easy to replace with local salon photography when available.

## Run locally
Open any HTML file directly in a browser, or run a simple static server from the project folder.
